# Adfluence

Adfluence is a multi-role influencer sponsorship platform that connects sponsors and influencers through campaigns, collaboration requests, and negotiation workflows.

Built using Flask, SQLAlchemy, and SQLite.

---

## Features

- Multi-role authentication system
- Sponsor and influencer dashboards
- Campaign creation and management
- Sponsorship request workflow
- Negotiation and deal handling
- Admin monitoring dashboard
- Profile and image management

---

## Tech Stack

- Python
- Flask
- SQLAlchemy
- SQLite
- Flask-Login
- HTML/CSS
- Jinja2

## Installation

```bash
git clone https://github.com/your-username/adfluence.git

cd adfluence

pip install -r requirements.txt

python main.py
```
